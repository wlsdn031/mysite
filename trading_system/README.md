# Trading System Skeleton

This package provides a basic structure for developing a long-only trading
system. The modules roughly correspond to the roadmap stages:

1. **Data** – ingestion and dataset preparation.
2. **Signals** – momentum, mean-reversion and vector-based indicators.
3. **Strategy** – position management and risk handling.
4. **Backtest** – historical performance evaluation.
5. **API** – connection layer to brokers or exchanges.
6. **Dashboard** – minimal Streamlit interface for monitoring.

All functions currently raise `NotImplementedError` and serve as placeholders
for future development.
